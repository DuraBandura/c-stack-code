# Программа: Вывод положительных чисел в обратном порядке (Стек)

## 📖 Описание
Программа на языке C, которая обрабатывает последовательность чисел:
- **Положительные числа** сохраняются в стек.
- При встрече **отрицательного числа** все сохранённые положительные выводятся в обратном порядке (из стека).
- Число **0** завершает работу программы.

### Пример работы:
Ввод: `5 3 8 -1 2 4 -2 0`  
Вывод: `8 3 5` (после первого минуса), затем `4 2` (после второго минуса).

---

## 🚀 Как запустить

### Вариант 1: Если у вас уже есть скомпилированный файл
В терминале в папке с проектом выполните:
```bash
./stack_positive
```
Затем вводите числа через пробел или по одному.

### Вариант 2: Скомпилировать самостоятельно
Если у вас установлен компилятор `gcc`:
```bash
gcc stack_positive.c -o stack_positive
./stack_positive
```

## 💻 Как выложить проект на GitHub

### Шаг 1: Создайте репозиторий на GitHub
1. Зайдите на [github.com](https://github.com).
2. Нажмите **+** в правом верхнем углу → **New repository**.
3. Придумайте имя (например, `stack-positive-c`).
4. Нажмите **Create repository**.

### Шаг 2: Привяжите локальный репозиторий к GitHub
В терминале в папке проекта выполните команды по очереди:

```bash
# Укажите ссылку на ваш новый репозиторий (замените YOUR_USERNAME на ваш логин)
git remote add origin https://github.com/YOUR_USERNAME/stack-positive-c.git

# Отправьте код на GitHub
git push -u origin main
```
*(Если ваша ветка называется `master`, замените `main` на `master`)*

### Шаг 3: Проверьте результат
Обновите страницу вашего репозитория на GitHub — там появится код и этот README.
